# 11 — HANDOFF / FUTURE MAINTENANCE

## Add a new title
1. add cover;
2. add sample if available;
3. add/update one book data object;
4. set accent;
5. set verified purchase links;
6. build;
7. visual smoke test.

No layout rewrite should be required.

## Publish Art
When released:
- confirm official Vietnamese title;
- set status to `published`;
- add verified Nhã Nam/Shopee URLs;
- add translator if verified;
- retain sample;
- remove/rework Coming Soon treatment based on data.

## Deployment URL
When known:
- set `siteUrl`;
- emit canonical;
- update structured data;
- rebuild.

## Commerce
Prefer stable product-detail URLs.
Do not mirror changing price/stock unless a live API is intentionally added later.
